# Release Builds

This directory contains the built Android application packages (APKs) for **FocusGuard** (NoScroll recreation).

## Available APK Downloads

| Variant | Filename | Description | Size |
|---|---|---|---|
| **Release (Recommended)** | `FocusGuard-release.apk` | Minified with R8, shrink-wrapped, and signed. Ready for end-user installation. | ~2.0 MB |
| **Debug** | `FocusGuard-debug.apk` | Unminified debug build with logging enabled. | ~19.5 MB |

> [!TIP]
> Download the latest signed release APK directly from our official [GitHub Releases](https://github.com/saurav-96/No-Scroll/releases/tag/v1.0.0) page.

## How to Install on Android

1. Download `FocusGuard-release.apk` onto your Android phone.
2. Open your phone's File Manager / Downloads and tap `FocusGuard-release.apk`.
3. Allow **"Install unknown apps"** if prompted.
4. Tap **Install** and open the app.
